# study-app-Lexis

Lexis - Comprehensive English Study & Mastery Platform.

## Features
- **Daily Vocabulary**: Contextual learning, word definitions, sentence tokens.
- **Reading Studio**: Curated articles with comprehension exercises.
- **Quiz Studio**: Active recall testing across CEFR levels.
- **Writing Workshop**: Automated essay feedback and structural upgrades.
- **Speaking Studio**: Pronunciation, scenario briefings, and audio recording.
- **Adaptive Study Plan**: Personalized curriculum generation and daily tracking.

## Development

```bash
cd study-app
npm install
npm run dev
```

## Production Build

```bash
cd study-app
npm run build
```
